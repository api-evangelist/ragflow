RAGFlow v0.27.0 is officially released. As the last major version with Python as the backend language, this release focuses on introducing a brand-new Knowledge Compilation Engine, an upgraded Agentic Retrieval framework, and a redesigned model provider configuration interface. Going forward, RAGFlow will position itself as an intelligent agent data foundation—built on knowledge compilation and serving various agent frameworks.
